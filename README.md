# Tasklane

A clean, modern personal Kanban board for students, solo professionals, and anyone managing personal tasks.

Tasklane is being developed with a spec-first workflow. The current product requirements are in [_docs/specs.md](_docs/specs.md).

## Status

The frontend prototype is in `frontend/`. It uses a temporary in-memory mock API
in `frontend/src/api/tasks.js`; a backend and database have not been implemented yet.
